# Quiz Infra, Redes & Segurança

Quiz de revisão com 27 questões do Enade (2017 e 2021) sobre redes de computadores, sistemas operacionais, arquitetura de computadores, computação em nuvem, segurança da informação e infraestrutura de TI.

Trabalho da Atividade Extensionista Curricularizada — Tópicos em Sistemas de Informação (8º período).

Grupo 4: Thiago Henrique Alves Cotrin, Iago de Souza Andrade e Pedro Henrique Silveira Fonseca.

Questões: Enade/Inep, uso educacional. Gabaritos conferidos nos gabaritos definitivos publicados pelo Inep.
